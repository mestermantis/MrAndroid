# اپ اندروید مدیریت HAFA — نسخه اصلاح‌شده

این پروژه فقط کلاینت اندرویدی جداگانه‌ای برای پنل آنلاین `https://hafaonline.ir/manager` است. فایل‌های سایت و پنل روی سرور تغییر نمی‌کنند.

## ساخت APK
1. ZIP را استخراج کنید.
2. تمام فایل‌ها و پوشه‌های داخل آن (از جمله پوشه مخفی `.github`) را در ریشه یک Repository جدید GitHub آپلود کنید.
3. در GitHub به تب Actions بروید و Workflow با نام `Build HAFA Android APK` را اجرا کنید.
4. پس از سبز شدن اجرای Workflow، وارد همان اجرا شوید و از بخش Artifacts فایل `HAFA-Android-Admin-APK` را دانلود کنید.
5. ZIP آرتیفکت را روی گوشی استخراج و فایل `app-release.apk` را نصب کنید.

با هر Push به شاخه main یا master نیز ساخت خودکار اجرا می‌شود.

## مشخصات
- عنوان نصب: مدیریت HAFA
- شناسه بسته: `ir.hafaonline.manager`
- حداقل اندروید: Android 6.0 (API 23)
- APK مستقل از ABI: از WebView سیستمی استفاده می‌کند و کتابخانه Native مخصوص CPU ندارد؛ یک خروجی برای دستگاه‌های پشتیبانی‌شده ARM/ARM64/x86/x86_64.
- پنل اصلی و نشست ورود از HTTPS سایت استفاده می‌کنند.
- انتخاب فایل، بارگذاری مجدد، بازگشت، و کلید پوسته روشن/تیره دارد.

## امضا
Workflow خروجی Release را با کلید debug داخلی Android امضا می‌کند تا برای نصب و آزمایش قابل استفاده باشد. برای انتشار عمومی یا فروشگاه‌ها باید keystore خصوصی و امضای Release اختصاصی تنظیم شود. کلید خصوصی را در مخزن عمومی قرار ندهید.

## اعلان‌ها
نسخه فعلی مجوز اعلان اندروید 13+ را درخواست می‌کند، اما این به معنی دریافت Push در حالت بسته بودن اپ نیست. پنل سایت از Web Push/Service Worker استفاده می‌کند؛ WebView اندروید دریافت Push قابل اتکایی مانند Chrome ندارد. برای اعلان واقعی بومی و پس‌زمینه، باید Firebase Cloud Messaging (FCM) در اپ و سرور PHP پیاده‌سازی شود. این پروژه عمداً هیچ فایل سایت را دستکاری نمی‌کند.

## نسخه V4 و خطای Failed to find package tools
در این Workflow دیگر هیچ‌جا پکیج قدیمی `tools` درخواست نمی‌شود. اکشن رسمی Android SDK فقط این بسته‌های معتبر را نصب می‌کند: `platform-tools`، `platforms;android-35` و `build-tools;35.0.0`. مرحله اجرای دستی `sdkmanager` نیز حذف شده است.
اگر مخزن GitHub شما فایل Workflow قدیمی دیگری دارد که هنوز `packages: tools platform-tools` نوشته، آن فایل را حذف یا اصلاح کنید؛ در غیر این صورت ممکن است Workflow قدیمی همچنان اجرا شود.
